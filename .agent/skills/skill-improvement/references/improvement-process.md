# Improvement Process

Use this process:

1. Capture the incident.
2. Reproduce when possible.
3. Identify root cause.
4. Determine whether the engineering process contributed.
5. Identify the smallest useful process change.
6. Update the appropriate skill.
7. Add regression protection.
8. Validate the change.
9. Record the lesson.

Do not modify skills simply because an implementation failed.

First determine whether a better rule would have prevented the failure.
