# Project Inspection

Before changing a .NET project inspect:

- solution files
- project files
- TargetFramework
- TargetFrameworks
- package references
- SDK configuration
- Directory.Build.props
- Directory.Build.targets
- global.json
- NuGet configuration
- analyzers
- nullable configuration
- implicit usings
- test projects
- build scripts
- CI configuration

Never assume the repository uses the latest .NET version.
