# Development Loop

Every meaningful code change follows:

## 1. Understand

Understand the requirement and acceptance criteria.

## 2. Inspect

Inspect the existing implementation and tests.

## 3. Plan

Determine affected components and testing strategy.

## 4. Test

Create or update the test representing expected behavior.

## 5. Confirm

Confirm the test fails for the expected reason when appropriate.

## 6. Implement

Make the smallest correct implementation.

## 7. Unit test

Run focused unit tests.

## 8. Integration test

Run or add integration tests where system boundaries are involved.

## 9. Validate

Build and run appropriate broader validation.

## 10. Review

Inspect the final diff.

## 11. Learn

If something went wrong, determine whether the engineering process
should improve.

## 12. Complete

Only report completion after actual validation.
