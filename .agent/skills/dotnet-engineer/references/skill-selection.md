# Skill Selection

Select the smallest set of skills required for the task.

## Always consider

- dotnet-engineer

## Feature development

Usually consider:

- dotnet10
- testing
- architecture
- code-review

## Bug fixing

Usually consider:

- dotnet10
- testing
- debugging
- code-review

## Refactoring

Usually consider:

- dotnet10
- testing
- architecture
- code-review

## Test-only changes

Usually consider:

- testing
- dotnet10
- code-review

## Architecture changes

Usually consider:

- architecture
- dotnet10
- testing
- code-review

## User-reported process failure

Consider:

- debugging
- testing
- skill-improvement

Do not invoke every skill for every task.
