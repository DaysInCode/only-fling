# Definition of Done

A development task is complete when:

- [ ] Requirement understood
- [ ] Existing implementation inspected
- [ ] Appropriate skills selected
- [ ] Implementation approach established
- [ ] Tests added or updated where appropriate
- [ ] New tests verified
- [ ] Implementation completed
- [ ] Unit tests pass
- [ ] Integration tests pass where applicable
- [ ] Build succeeds
- [ ] Relevant validation succeeds
- [ ] No unexplained failures remain
- [ ] Git diff reviewed
- [ ] No accidental changes remain
- [ ] Security implications considered
- [ ] Performance implications considered where relevant
- [ ] User requirement satisfied
