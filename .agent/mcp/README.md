# MCP Integration

MCP servers provide capabilities.

Skills provide engineering knowledge and workflow.

Keep those responsibilities separate.

## Examples of MCP capabilities

Potential MCP servers may provide:

- database inspection
- browser automation
- API inspection
- documentation search
- Git hosting
- issue tracking
- cloud infrastructure
- observability
- container management

Do not assume an MCP server exists.

Before using an MCP capability:

1. Determine whether the server is available.
2. Determine whether it is relevant.
3. Use the smallest necessary capability.
4. Validate important results.

MCP output is evidence, not automatically truth.
